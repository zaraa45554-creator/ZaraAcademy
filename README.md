# Zaraa Academy – IOB Exam Preparation

Frontend-only IOB exam preparation portal built with HTML, CSS and JavaScript.

## Included
- Name + email student login
- Dashboard and topic navigation
- **140+ educational/demo questions** across Banking Awareness, Quantitative Aptitude, Reasoning, English, Computer Knowledge, General Awareness and Current Affairs
- Search and topic filtering
- 10/20/30-question practice tests
- Full mock exam with 20-minute timer
- Automatic scoring and answer review
- Result history in browser localStorage
- Mobile responsive UI

## Run
Open `index.html` in a browser.

## Note
The question bank is educational/demo content. For an actual exam-preparation product, verify current-affairs and exam-specific content against authoritative sources.
